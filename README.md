# 📊 Logistics Performance Portfolio Project

Un progetto end-to-end di Business Intelligence e Data Analysis focalizzato sull'analisi delle prestazioni logistiche, dei tempi di consegna e dell'efficienza dei corrieri.

---

## 🚀 Panoramica del Progetto
L'obiettivo di questo progetto è analizzare i dati logistici aziendali per identificare eventuali colli di bottiglia nelle spedizioni, monitorare le performance dei corrieri e fornire una panoramica geografica chiara delle consegne attraverso una dashboard interattiva.

---

## 🛠️ Tecnologie e Strumenti Utilizzati
- **Database / SQL**: MySQL (`LogisticsPerformanceDB`) per la gestione, strutturazione e pulizia dei dati.
- **Data Modeling**: Creazione di un modello a stella (Star Schema) ottimizzato per le performance di calcolo.
- **Business Intelligence**: Power BI Desktop (`Logistics_Performance_Project.pbix`) per la visualizzazione dei dati.
- **Linguaggio DAX**: Scrittura di misure personalizzate per il calcolo delle metriche chiave di spedizione.
- **Version Control**: GitHub per l'hosting e la documentazione del codice/progetto.
